# Dashboard template attribution

The Waterline UI uses the **AdminLTE 4.10.0** dashboard template by
[ColorlibHQ / AdminLTE](https://github.com/ColorlibHQ/AdminLTE),
licensed under the MIT License.

The compiled AdminLTE CSS and JavaScript are copied without bundled demo images,
with the upstream licence notice preserved in the vendor folders.

Other HTML and CSS customisations are original to Water Allowance Tracker.
No proprietary licensed Colorlib downloaded ZIP, demo photo, hosted font,
premium or subscription template is included.

To update assets, use npm ci, then npm run sync:template, review the
licences and changed files, and run tests before publishing.
