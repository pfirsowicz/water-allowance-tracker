# Dashboard template

- UI template: [AdminLTE 4.10.0](https://github.com/ColorlibHQ/AdminLTE) by ColorlibHQ, MIT-licensed.
- Compiled CSS/JS is included; upstream licence notices remain in vendor folders.
- No commercial template ZIP, premium assets, hosted fonts or third-party demo images are included.
- App-specific HTML/CSS changes are separate from the upstream template.
- To refresh: `npm ci` → `npm run sync:template` → review assets/licences → run tests.
